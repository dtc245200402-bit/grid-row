# Thực hành CSS: grid-row Property

## Nội dung
- `index.html`: trang tổng hợp ba ví dụ.
- `example-1.html`: `grid-row: 1 / 3`.
- `example-2.html`: `grid-row: 2 / 4`.
- `example-3.html`: `grid-row: span 2`.
- `style.css`: toàn bộ định dạng và bố cục responsive.
- `screenshots/`: ảnh chụp kết quả từng ví dụ và toàn trang.

## Chạy bài
Mở `index.html` bằng trình duyệt. Không cần cài thư viện hay chạy server.

## Thuộc tính được minh họa
- `grid-row: 1 / 3`: Ô 1 bắt đầu ở đường kẻ hàng 1, kết thúc ở đường kẻ hàng 3 nên chiếm hai hàng đầu.
- `grid-row: 2 / 4`: Ô 1 chiếm hàng 2 và hàng 3.
- `grid-row: span 2`: Ô 1 chiếm hai hàng, còn vị trí bắt đầu do Grid tự bố trí.
